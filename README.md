# Paint Shop

A lightweight Windows desktop painting app built with PowerShell and Windows Forms. It runs on Windows with Windows PowerShell 5.1 and does not need an installer or third-party packages.

## Start

Double-click **Launch Paint Shop.bat**. You can also run `PaintShop.ps1` from Windows PowerShell.

## Features

- Freehand brush, eraser, and straight-line tools
- Brush sizes from 1 to 80 pixels
- Color palette and custom color picker
- Undo and redo (up to 30 drawing actions)
- Open and save PNG, JPEG, and BMP images
- Resize and clear the canvas
- File, Edit, View, and Help menus in a compact toolbar layout
- Keyboard shortcuts: Ctrl+O, Ctrl+S, Ctrl+Z, Ctrl+Y

Canvas resize keeps artwork at the top left; shrinking the canvas clips artwork outside its new dimensions.
